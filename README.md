# Film

Онлайн-кинотеатр: фан-сайт о «Ходячих мертвецах» и **полные фильмы, которые можно смотреть легально и бесплатно**.

## Откуда берутся полные фильмы

Сайт показывает только фильмы в **общественном достоянии** (public domain): у них истёк срок авторских прав
или их выпустили без охраны. Видео транслируется официальным встраиваемым плеером
[Internet Archive](https://archive.org/details/feature_films), так что сайту не нужно хранить видео самому.

- **Подборка редакции** (`src/data/catalog.js`): 10 проверенных фильмов, среди них «Ночь живых мертвецов» (1968),
  «Белый зомби» (1932), «Последний человек на Земле» (1964), «Носферату» (1922), «Генерал» (1926) и другие.
- **Живой каталог**: разделы «Фильмы», «Анимация» и «Сериалы» подгружают тысячи записей из тематических коллекций
  Internet Archive (`feature_films`, `animationandcartoons`, `classic_tv`), с поиском, сортировкой и подгрузкой.
- Плеер открывает только записи из этих коллекций или из подборки. Произвольную загрузку с archive.org
  по прямой ссылке `/watch/<id>` на сайте не показать.

Полные серии самих «Ходячих мертвецов» защищены авторским правом. Показывать их можно только по лицензии
правообладателя (AMC), поэтому на сайте есть описание сериала и сезонов, но не сами серии.

Чтобы добавить фильм в подборку, найдите его на archive.org, убедитесь, что он в общественном достоянии
(пометка *Public Domain* или коллекция `feature_films`), и допишите объект в `FEATURED` в `src/data/catalog.js`.
Идентификатор — это часть адреса после `archive.org/details/`.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install

# Разработка: сайт на http://localhost:5173, API на :3000 (с автоперезапуском)
npm run dev

# Продакшен: сборка и запуск одного сервера на http://localhost:3000
npm run build
npm start

# Тесты сервера и защиты
npm test
```

### Настройки сервера (переменные окружения)

| Переменная | Назначение |
| --- | --- |
| `PORT` | Порт, по умолчанию `3000` |
| `HOST` | Адрес, по умолчанию `127.0.0.1`. Для Docker или внешнего доступа: `0.0.0.0` |
| `PUBLIC_ORIGIN` | Публичный адрес сайта, например `https://film.example`. Со значением `https://…` включаются HSTS, Secure-cookie и `upgrade-insecure-requests`, а запросы с других адресов отклоняются |
| `TRUST_PROXY` | Сколько прокси (nginx, Cloudflare) стоит перед сервером, например `1`. Нужно, чтобы лимиты считались по реальному IP |
| `DATA_FILE` | Путь к файлу с пользователями и сообщениями, по умолчанию `data/db.json` |

## Возможности

- Новый адаптивный тёмный дизайн: главная с баннером, сетки карточек, мобильное меню, скелетоны загрузки
- Страница просмотра `/watch/:id` со встроенным плеером, описанием и похожими фильмами
- Поиск по подборке и каталогу, фильтр по жанрам, сортировка, «Показать ещё»
- Избранное (хранится в браузере и синхронизируется между вкладками)
- Регистрация и вход с проверкой пароля и индикатором надёжности
- Форма «Сообщить об ошибке»
- Страница 404, ссылка «Перейти к содержимому», поддержка `prefers-reduced-motion`

## Безопасность

Меры защиты от взлома и фишинга и чек-лист для публикации сайта описаны в [SECURITY.md](SECURITY.md).

## Структура

```
server/         Express-сервер: API, авторизация, защита, прокси каталога Internet Archive
  test/         Тесты (node --test)
shared/         Правила проверки данных, общие для сервера и браузера
src/
  Components/   Шапка, подвал, карточки, плеер, поля форм
  pages/        Страницы сайта
  data/         Подборка фильмов
  lib/          API-клиент, авторизация, избранное
public/         favicon, robots.txt, security.txt, _headers для статического хостинга
```
